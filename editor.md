# Beatmap Editor Usage Documentation

- All changes are saved immediately when they are made.
- Cursor: the yellow markers on the lanes

<br>

- "<", ">" buttons: scrub left, right in the beatmap
- "!" button:
  - If note exists at cursor, remove note
  - Else, add note of selected note type (use the dropdown menu) at cursor
    - If selected note type is "Hold" the editor locks the map so you can only move to the right and
      once you've moved the cursor to where the note should end, press "!" again to finish adding
      the note
